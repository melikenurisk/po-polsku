# Po Polsku 🇵🇱

A personal Polish learning platform built from my Busuu A1–A2 vocabulary.

**Live site:** [https://melikenurisk.github.io/po-polsku/](https://melikenurisk.github.io/po-polsku/)

## What's inside

| Section | Description |
|---------|-------------|
| **Vocabulary** | 390+ words organized by 17 themes with search, filters, and strength indicators |
| **Grammar Book** | 18 chapters covering A1→A2 grammar in 5 categories (collapsible) |
| **Quiz: PL→EN** | Polish to English — multiple choice or type the answer |
| **Quiz: EN→PL** | English to Polish — with Polish keyboard helper and diacritics feedback |
| **Grammar Quiz** | Conjugation, cases, tenses, negation, and question formation |

## Features

- Works on phone, tablet, and desktop
- Dark mode (synced across all pages)
- Quiz progress saved in browser (localStorage)
- Strength-based quiz prioritization (weak words appear more often)
- No internet required after first load
- No frameworks, no build tools — just HTML, CSS, and JS

## How to use

Open `index.html` in any browser, or visit the GitHub Pages link above.

## Tech

- Static HTML pages with shared CSS/JS
- `vocabulary.json` → single source of truth for all word data
- Shared design system: `css/base.css`, `css/components.css`, `css/layout.css`
- Shared navigation and dark mode: `js/shared.js`
